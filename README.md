## Overview

This repository contains the formal **Lean 4** proofs, **Python** symbolic/numerical verification suites, **SystemVerilog** FPGA hardware architectures, and technical preprints for the **Seven-Valued Logic of Time (7VL)** framework.

7VL is an axiom-free, pre-geometric mathematical and computational framework grounded in finite permutation transitions ($S_3 \leftrightarrow S_4$), Hamming error-correcting codes ($[7,4,3]_2$), finite projective geometry ($\mathrm{PG}(2,2)$), and Clifford algebras ($\mathrm{Cl}_{4,4}(\mathbb{R})$). All core finite-group, Clifford-algebraic, anomaly-cancellation, and rational flavor identities are **machine-checked in standalone Lean 4** without external axioms or `sorry`.
